# oxlint-plugin-jev (vendored source)

- Source: https://github.com/K-Mistele/oxlint-plugin-jev, a fork of oxlint-plugin-jev by Robert Soriano (MIT, see `LICENSE`).
- Commit: `741b19b0efd441f84d6e17906d95366cf38e94a4`. The fork's later `main` (`fd3e4b1`) only adds a decision backend for a hosted coding-agent service, a `prepare` build script, and README changes, none of which Flywheel uses.
- Contents: the TypeScript files of `src/`, copied verbatim and then changed as the ledger below states. Its tests, build configuration, and examples are not vendored. `tests/integration/oxlint-plugin-jev.test.ts` covers the decision backend switch.
- Oxlint loads `src/index.ts` directly as a JS plugin under `bunx --bun oxlint`, and synckit starts `src/worker.ts` in a Bun worker thread, so there is no build step.

## Replacement ledger

| File | Change | Reason |
|---|---|---|
| all files with lint findings | One `// oxlint-disable ... -- vendored upstream source keeps its own style` line at the top | `bun run lint` lints `scripts/` with Flywheel's style rules; the donor code keeps its shape |
| `src/backend.ts` | Rewritten: `chooseDecisionBackend(env, defaults)` reads `ANTI_SLOP_DECISION_MODEL` (`typesafe:<model>` or `openai:<model>`), else TypeSafe when `TYPESAFE_API_KEY` is set, else OpenAI Decisions `gpt-6-luna` when `OPENAI_API_KEY` is set, else a missing-credential result. A malformed setting throws. AI Gateway, `TYPESAFE_AI_API_KEY`, and the LLM judge backend are removed | One switch picks the decision backend; Flywheel uses only TypeSafe Jev and OpenAI Decisions, and the design rejected judging with chat models |
| `src/decision-model.ts` | New: `decisionModelFor(backend)` builds the AI SDK decision model with `@ai-sdk/typesafe-ai` or `@ai-sdk/openai`, and `decisionProviderOptions(backend)` sends TypeSafe's long-context option | Shared by the worker and the diff rules in `scripts/anti-slop-llm/diff-rules/`, without the worker's `runAsWorker` side effect |
| `src/worker.ts` | The `judge` path, the AI Gateway model, and the cached TypeSafe provider are removed; `decide` takes its model from `decisionModelFor` | Follows the backend change |
| `src/types.ts`, `src/options.ts`, `src/index.ts` | `JudgeOptions`, the `judge` option, and its schema are removed; `Backend` is `typesafe` or `openai`; file rules always ask for a location; the rule description names both decision APIs | Follows the backend change; both decision APIs answer choice questions |
| `src/answers.ts` | Uncached asks are split into requests of at most 100,000 characters of serialized request, framing, questions, and location criteria included; `answerAll` takes one absolute `deadline` instead of `timeoutMs`, gives each request what is left of it, and fails with `timeout` once it passed | Token-dense source, such as hex literals, runs at about 1.7 characters per token, so the budget keeps every request under the decision models' 64k-token limit; a split answer or a location refinement must not get a fresh timeout per request |
| `src/sync-jev.ts` | The worker URL names `worker.ts` instead of the built `worker.mjs`; `askModel(backend, request, timeoutMs)` passes the backend through `backendToWire` | The source runs without a build; see the `Redacted` row |
| `src/changed.ts` | `windowsHide: true` on the `git` launch | Flywheel launches every child process with a hidden console window on Windows |
| `src/jev.ts`, `src/options.ts` | A non-null assertion, with a `// SAFETY:` comment that names its invariant, on six index reads that the surrounding code proves present (`locationCandidates` two, `selectedLocation` two, `locationOfLine` one, `validate` one) | Flywheel type-checks `scripts/` with `noUncheckedIndexedAccess`, and every non-null assertion states its invariant |
| `src/types.ts`, `src/backend.ts`, `src/decision-model.ts`, `src/worker.ts` | `Backend` holds its API key as an Effect `Redacted`, and `AskInput` carries a `WireBackend` with a plain key. `backendToWire` unwraps the key at the synckit boundary and `backendFromWire` wraps it again in the worker; `decisionModelFor` unwraps it for the AI SDK | Flywheel holds every secret as `Redacted` in memory; a structured clone drops what a `Redacted` holds, so the worker boundary is the one serialization point |
| `src/index.ts` | A missing decision credential always warns once and skips, also under CI with `ci: 'fail'`, which now governs failed requests only; the initial requests and the location refinement of one file share the deadline set before the first request | Paid checks are opt-in, so a missing key is never a failure; one deadline bounds the whole operation |
| `src/jev.ts`, `src/index.ts` | `buildRequest` returns each ask with its question id, and a pass keeps each match with its asks, instead of parallel arrays read by index | Removes three non-null assertions that TypeScript could not prove |
