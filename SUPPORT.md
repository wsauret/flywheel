# Getting help

- **Questions:** ask in the [Q&A discussions](https://github.com/wsauret/flywheel/discussions/categories/q-a). Search the existing discussions first; your question may already have an answer.
- **Bugs:** open a [bug report](https://github.com/wsauret/flywheel/issues/new/choose). Include the output of `flywheel --version`, your platform, and the steps that cause the problem.
- **Feature requests:** open a feature request from the same page, or start an idea in [Ideas](https://github.com/wsauret/flywheel/discussions/categories/ideas) when you want to talk it through first.
- **Security problems:** do not post them in public. Follow [SECURITY.md](SECURITY.md).

Only the latest release is supported. Run `flywheel update` before you report a problem, and check whether it still happens.
