## Ask for a change

Flywheel is not a chat window that prints suggestions for you to copy. Ask it
for a change and it edits the files.

    Add tests for the file I have open
    Find and fix the failing test
    Rename this function everywhere it is used

Two shortcuts worth knowing:

- Select code and press **⌘⇧L** to send it along with your question.
- Press **⌘⇧U** to attach whole files.
