# Mechanism Verification

Start with a docket of precise behavioral or runtime claims and the repository revision. Normalize each claim into trigger, mechanism, and observable consequence. Trace the actual call and state path. Verify reachability, ordering, ownership, cancellation, race, crash, and durability premises that matter, and cite every decisive edge.

Stop when every claim is `confirmed`, `refuted`, or `uncertain`. Return each claim, verdict, causal trace, exact `path:line` evidence, and missing evidence for `uncertain`. Never assign review severity, synthesize findings, or decide whether a workflow proceeds.
