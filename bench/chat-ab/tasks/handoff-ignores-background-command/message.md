In a workflow step, the agent started `bun run test:perf` as a background command and then called handoff right away. The step ended while the perf run was still going, so the command was cut off, and the handoff reported results that the agent never saw. Subagents do not have this problem: handoff refuses while a subagent is still running, and again until the agent has seen the subagent's result. A step must not be able to hand off while one of its own background commands is still running, or before the command's result has reached the agent.
