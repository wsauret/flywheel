When the runtime interrupts a running subagent (for example during an update), the parent agent keeps waiting on it: its waits park on the subagent until they expire, and it cannot hand off, because the subagent still counts as its outstanding work. The parent is also never told that the runtime interrupted the subagent. The subagent's background record says "stopped", but nobody stopped it: it is only interrupted, and it can resume later from its viewer. Every other place in Flywheel calls this state "interrupted". Please record an interrupted subagent as interrupted, and make a subagent that the runtime interrupted stop holding the parent's waits and handoff. When I interrupt a subagent myself, it must stay the parent's work, as it does now. A subagent whose run really fails must still record as failed.
