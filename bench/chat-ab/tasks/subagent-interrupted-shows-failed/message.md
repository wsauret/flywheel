When I interrupt a running subagent (or the runtime interrupts it, for example during an update), the parent agent thinks the subagent failed. The subagent did not fail: it is only interrupted, and I can resume it later from its viewer. Every other place in Flywheel calls this state "interrupted". Please make the parent's process list show an interrupted subagent as interrupted. A subagent whose run really fails must still show as failed.
