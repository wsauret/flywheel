When my agent starts a long build or a subagent in the background and then waits on it with the process tool a few times, it gets a repetition notice ("The same tool call has repeated 3 or more times with the same input. Do not repeat it again: try a different approach.") right after the work finishes. Those waits were legitimate: the agent was waiting for work that was still running, and each wait ended when something finished. After the notice, the agent often drops a perfectly good plan. Please stop the notice in this case. A real loop must still get the notice, for example an agent that waits again and again when nothing is running, or one that keeps retrying the same failing command between waits.
