Try a different approach." message right after the work finishes. Those waits were legitimate: the agent was waiting for work that was still running, and each wait ended when something finished. After the nudge, the agent often drops a perfectly good plan. Please stop the nudge in this case. A real loop must still get the nudge, for example an agent that waits again and again when nothing is running, or one that keeps retrying the same failing command between waits.
