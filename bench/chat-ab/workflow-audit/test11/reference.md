# Reference answer: what this repository is

This repository is Flywheel, a coding-agent command-line tool written in TypeScript that runs on Bun, with a terminal interface built on OpenTUI and SolidJS. It runs agents against several model providers and orchestrates their work through sessions, subagents, and workflows. A two-sentence answer that says it is a coding-agent CLI and names its stack or its agent orchestration is complete.
