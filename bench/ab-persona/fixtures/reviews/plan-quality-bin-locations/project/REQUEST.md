# Request: bin locations on the pick list

From the warehouse lead.

Pickers lose time looking for items. Every shelf bin has a code: aisle letter, two-digit shelf, bin digit, for example `A-03-2`.

1. The pick list shows the bin code of each line. A line whose item has no bin yet shows `-`.
2. A stock clerk can set the bin code of an item from the warehouse terminal, or clear it when the item leaves its bin. A code in any other shape is rejected with a message.

The order of the lines on the pick list does not change.
