# Why this task exists

This broad task measures whether a model can plan one policy across an external model boundary, workflow attempt control, and durable event publication. A local length check is not sufficient. The plan must explain where canonical bytes are measured, how rejection becomes workflow state, and why no partial handoff reaches SQLite.

## Must-address verification

1. **Registered handoff contract remains canonical.** `src/workflows/handoffs/registry.ts` defines `HandoffType` with `schema`, optional `preprocess`, and optional `validators`. `src/orchestration/handoff-tool-schema.ts` derives the runtime tool schema from that registered type. The registry test rejects execution-specific content and `JSON.stringify`. This point catches a second hardcoded payload schema or runtime policy inside the workflow registry.
2. **Configuration ownership and threading.** `src/orchestration/config/schema.ts` owns `FlywheelConfigSchema`, and `src/orchestration/config/loader.ts` decodes TOML through that schema. `createWorkflowHost` already receives decoded configuration and creates the worker callback and attempt runner. This point catches global reads and a forbidden workflows-to-orchestration dependency.
3. **Canonical byte measurement.** `buildHandoffWrittenFact` serializes `input.content` with `JSON.stringify` before it calls `contentEvidence`. `contentEvidence` converts strings with UTF-8 encoding and records `Buffer.byteLength`. This point catches UTF-16 string length, preview length, and estimates that fail on non-ASCII data.
4. **Model-facing writer rejection.** `createHandoffToolCore.execute` recovers malformed framing, checks required fields, decodes the registered schema, runs mechanical validators, and then calls `handoff.onContent`. This is the last model-facing boundary before capture. Its existing errors return `outcome: "error"` and do not terminate the agent. This point catches checks that run only after capture or report an incomplete error.
5. **Worker to attempt failure path.** `src/orchestration/worker-callback.ts` stores accepted tool data in `capturedHandoff` and returns it as `handoffContent`. `createAttemptRunner` in `src/workflows/vm/attempt-runner.ts` converts missing and invalid handoffs into attempt failures. `AttemptFailureSchema` in `src/workflows/vm/events.ts` is the typed failure union. This point catches a tool error that never becomes an explicit workflow attempt result.
6. **Existing retry and pause semantics.** `failAttempt` in `src/workflows/vm/attempt-transitions.ts` recognizes authored handoff failures, inserts retries within the authored limit, and pauses after the retry path is not available. This point catches a new state machine or an unbounded retry loop.
7. **Atomic handoff publication.** `completionFacts` in `src/workflows/vm/companions.ts` creates `handoff.written` and `handoff.validated` companion facts. `createWorkflowHostCommitController` composes them before `commitOrRehydrate`, and `createWorkflowCommitHost` in `src/workflows/vm/commit-host.ts` writes the proposal with one awaited `appendBatch`. This point catches direct event writes and partial commits.
8. **Strict fact and replay contract.** `HandoffWrittenFactSchema` requires content, bytes, hash, and preview. `reduceHandoffEvent` parses each stored fact and folds written and validated evidence without repair behavior. This point catches truncation, optional evidence, and tolerant replay of malformed internal data.
9. **Module boundary direction.** `scripts/check-boundaries.ts` defines `workflows-imports-infra-only` and permits orchestration to import workflows, not the reverse. This point catches configuration imports in workflow modules and misplaced runtime tool logic.
10. **Boundary and durable tests.** `tools-handoff.test.ts` already tests successful capture and error-without-capture behavior. `companions.test.ts` tests successful, invalid, and missing handoff evidence. `vm-commit-protocol.test.ts` verifies atomic success facts and failed-handoff retry facts. These seams can prove byte boundaries, multibyte behavior, failed-attempt propagation, and durable consequences.
